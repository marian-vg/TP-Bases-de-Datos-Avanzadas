=============================================================================
SMART CITY - GUÍA DE EJECUCIÓN OPERATIVA MULTIPLATAFORMA
=============================================================================

Este proyecto cuenta con orquestación automática para levantarse de forma limpia
tanto en sistemas Linux como en Windows mediante scripts automatizados.

-----------------------------------------------------------------------------
1. REQUERIMIENTOS PREVIOS
-----------------------------------------------------------------------------
Asegúrese de contar con los siguientes elementos instalados en su sistema:
  * Docker Engine (v20.10 o superior)
  * Docker Compose (v2.0 o superior)
  * Puertos 80 (o 5173 en Windows local) y 5432 libres localmente

-----------------------------------------------------------------------------
2. INSTRUCCIONES PARA LINUX
-----------------------------------------------------------------------------
Levantar la aplicación (compila, levanta BD, aplica resets y orquesta juego):
  $ chmod +x start-game.sh stop-game.sh
  $ ./start-game.sh

Una vez finalizado, acceda a: http://localhost:80

Apagar el entorno de forma limpia:
  $ ./stop-game.sh

-----------------------------------------------------------------------------
3. INSTRUCCIONES PARA WINDOWS
-----------------------------------------------------------------------------
Levantar la aplicación (compila, espera salud de BD y abre navegador):
  * Haga doble click en el archivo: start-smart-city.cmd
  * O bien, ejecute desde PowerShell: .\start-smart-city.ps1

Una vez finalizado, acceda a: http://localhost:5173

Apagar el entorno de forma limpia:
  * Haga doble click en el archivo: stop-smart-city.cmd
  * O bien, ejecute desde PowerShell: .\stop-smart-city.ps1
